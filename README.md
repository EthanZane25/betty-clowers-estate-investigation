# Betty Jean Clowers Estate Investigation

## Purpose

This repository is a public evidence and research file concerning the estate of Betty Jean Clowers.

It is intended to organize:
- public probate records
- wills and estate-planning documents
- property/deed history
- service-of-process records
- medical-capacity leads
- life-insurance leads
- cremation/disposition records
- witness and relationship research
- documented contradictions and unresolved questions

## Evidence Rules

Every factual statement should be labeled when appropriate:

- DOCUMENTED — supported by a primary record
- CORROBORATED — supported by multiple independent sources
- REPORTED — supplied by a witness/family member but not yet independently proven
- LEAD — requires further verification
- DISPUTED — conflicting evidence exists
- INFERENCE — interpretation, not itself a proven fact
- NOT ESTABLISHED — evidence is insufficient

This repository does not presume criminal wrongdoing by any person. It is intended to preserve records and identify questions requiring verification.
