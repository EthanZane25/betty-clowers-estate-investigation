# Probate Documents

- `original-files/` contains the PDF files originally supplied during the investigation under their original filenames.
- `clean-names/` contains identified unique documents under descriptive filenames. These are organizational copies; source content was not edited.
- `official-source/` contains PDFs downloaded from the official Georgia Probate Records source, plus source URL metadata and SHA-256 files.
- `source-records/` preserves source-page HTML where available.
- `SOURCE_MANIFEST.md` maps names, source URLs, dates, and evidence status.
- `SHA256SUMS.txt` provides integrity hashes where generated.
