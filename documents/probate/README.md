# Probate Documents

- `original-files/` contains all 15 PDF files supplied during the investigation under their original filenames.
- `clean-names/` contains identified unique documents under descriptive filenames. These are copies only; the PDF content was not edited.
- `SOURCE_MANIFEST.md` maps original names, clean names, source URLs, dates, and duplicate status.
- `SHA256SUMS.txt` provides integrity hashes.
- `scripts/download_from_official_source.sh` can attempt to re-download the official Georgia Probate Records scans, including the still-missing Sheriff's Return.
